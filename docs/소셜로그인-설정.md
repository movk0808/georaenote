# 구글·카카오·네이버 로그인 켜기

웹의 로그인 화면에는 이미 '카카오로 시작하기', '구글로 시작하기' 버튼이 들어 있어요.
아래처럼 각 개발자 센터에서 키를 받아 Supabase에 넣고, 웹 설정에 이름만 적으면 버튼이 나타나요.
사업자등록 없이 할 수 있어요(카카오는 닉네임·프로필 사진만 받는 기본 로그인 기준).

로그인 후 돌아올 주소(Redirect URI)는 둘 다 같아요.

```
https://xqrsafvgkbzetlimiwok.supabase.co/auth/v1/callback
```

## 1. 구글

1. https://console.cloud.google.com 접속 → 새 프로젝트 만들기(이름 예: 거래노트)
2. **API 및 서비스 → OAuth 동의 화면**
   - 사용자 유형: 외부
   - 앱 이름: 거래노트, 지원 이메일 입력
   - 범위: `email`, `profile`, `openid`만 선택(심사 없이 쓸 수 있는 기본 범위)
   - 앱 도메인에 개인정보처리방침 주소를 넣고 **앱 게시**를 누르면 누구나 로그인할 수 있어요
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: 웹 애플리케이션
   - 승인된 리디렉션 URI: 위 주소
   - 만들고 나온 **클라이언트 ID**와 **클라이언트 보안 비밀번호**를 복사
4. Supabase 대시보드 → 프로젝트 → **Authentication → Sign In / Providers → Google**
   - Enable 켜기, 클라이언트 ID와 보안 비밀번호 붙여넣기 → Save

## 2. 카카오

(2026-11-13 완료: 앱 ID 1649650, 개인 개발자 비즈 앱)

1. https://developers.kakao.com 로그인 → **앱 → 앱 생성**(앱 이름·회사명: 거래노트, 카테고리: 금융, 도메인: `https://movk0808.github.io`)
2. **제품 설정 → 카카오 로그인 → 일반**: 상태 ON
3. **앱 설정 → 앱 → 플랫폼 키 → REST API 키** 를 눌러
   - 카카오 로그인 리다이렉트 URI: 위 주소 → 저장
   - 같은 화면의 **클라이언트 시크릿 → 카카오 로그인** 코드(기본 활성화)를 Supabase에 씀
4. **Supabase는 이메일·프로필 사진·닉네임 권한을 항상 함께 요청**해요. 셋 다 동의항목에 켜져 있지 않으면 로그인 후 KOE205 오류가 나요
   - 앱 아이콘 등록 → **앱 → 일반 → 개인 개발자 비즈 앱 전환**(본인인증·약관 동의, 사업자 번호 없이 가능)
   - **카카오 로그인 → 동의항목**: 닉네임 필수, 프로필 사진·카카오계정(이메일) 선택 동의
   - 카카오톡 채널 만들기 화면이 나와도 로그인에는 필요 없어요
5. Supabase 대시보드 → **Authentication → Sign In / Providers → Kakao**
   - Enable 켜기
   - REST API Key 칸에는 REST API 키 값(이름 아님), Client Secret 칸에는 카카오 로그인 코드. 크롬이 저장된 아이디·비밀번호를 자동으로 채우면 지우고 넣기
   - 이메일 없이 가입을 허용하는 옵션(Allow users without an email)이 있으면 켜기 → Save

## 3. 네이버

네이버는 Supabase가 기본 지원하지 않아서 서버 함수 `auth-naver`가 대신 처리해요(배포 완료).

1. https://developers.naver.com → **Application → 애플리케이션 등록**
   - 애플리케이션 이름: 거래노트
   - 사용 API: **네이버 로그인**, 제공 정보는 **별명**만 필수로(이메일 등은 받지 않아도 돼요)
   - 로그인 오픈 API 서비스 환경: **PC 웹**
     - 서비스 URL: `https://movk0808.github.io`
     - 네이버 로그인 Callback URL: `https://xqrsafvgkbzetlimiwok.supabase.co/functions/v1/auth-naver`
2. 등록하면 나오는 **Client ID**, **Client Secret**을 서버 함수 비밀값으로 넣어요(PowerShell, 프로젝트 폴더에서)
   ```
   npx.cmd supabase secrets set NAVER_CLIENT_ID=<Client ID> NAVER_CLIENT_SECRET=<Client Secret> --remote=xqrsafvgkbzetlimiwok
   ```
   또는 Supabase 대시보드 → Edge Functions → Secrets 에서 같은 이름으로 추가
3. 처음엔 '개발 중' 상태라 **멤버관리**에 등록한 네이버 아이디만 로그인돼요.
   누구나 쓰게 하려면 **검수 요청**을 해야 해요(서비스 화면 캡처 등 제출).

## 4. 웹에 버튼 켜기

키 등록이 끝난 로그인만 적어요(쉼표로 구분).

- 배포 사이트: GitHub 저장소 → Settings → Secrets and variables → Actions → Variables
  - `VITE_AUTH_PROVIDERS` = `google,kakao,naver`
  - 저장 후 web 폴더를 한 번 다시 배포하면 돼요(제게 말씀하시면 다시 배포해 드려요)
- 내 PC 개발 서버: `web/.env.local`에 `VITE_AUTH_PROVIDERS=google,kakao,naver` 한 줄 추가

## 로그인 방식이 섞일 때

- 구글·카카오·네이버·바로 시작으로 들어온 사람은 자동 닉네임(멋진사장님12 같은)을 받아요.
- 계약 등록과 결제 직전에 휴대폰 본인인증을 한 번 받아요. 인증하면 그 번호로 휴대폰 번호 로그인도 돼서, 안드로이드 앱에서도 같은 계정을 볼 수 있어요.
- 한 번호는 한 계정에서만 인증할 수 있어요. 이미 다른 계정에서 인증한 번호면 "휴대폰 번호로 로그인해 주세요"라고 안내해요.

## 안드로이드 앱의 구글·카카오 로그인

앱은 지금 바로 시작과 휴대폰 번호 로그인을 지원해요. 앱에서 구글·카카오 로그인을 쓰려면 위 키가 준비된 뒤에 브라우저로 로그인했다가 앱으로 돌아오는 연결(딥링크)을 추가하면 돼요.
